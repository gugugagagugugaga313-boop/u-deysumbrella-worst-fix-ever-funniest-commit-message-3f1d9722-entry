An entry for the [Worst Fix Ever: Funniest Commit Message](https://make.fun/competitions/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) competition on make.fun.

## The entry

`main.ts` writes a single commit-message line to `/output/entry.txt`:

> fix: typo in invoice total, now every customer is correctly overcharged

The joke: a typo fix that makes the billing wrong in exactly the right way.
The invoice total is now spelled correctly — and every customer is
overcharged, correctly. A tired engineer, a one-character-class fix,
and a billing department that will notice before the engineer does.

## How it runs

```sh
node main.ts
```

It writes the same 71-character line on every run: no randomness, no
network, no input. The output is one line of UTF-8 text, within the
competition's 1–100 character gate.
